# Zero University experience

Local reproduction of `https://why.zero.university/` captured on September 12, 2026.

## Run

```powershell
npm run start
```

Open `http://127.0.0.1:4173`.

The experience uses WebGL, audio, compressed KTX2 textures, GLB models, and MP4 video. Use a current desktop browser with hardware acceleration enabled.

## Deploy to Vercel

Import this repository in Vercel and leave the framework preset as **Other**. No build command or output directory is required; Vercel serves the root `index.html` and static asset directories directly.
